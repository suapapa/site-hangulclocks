# HangulClocks: 여러분의 한글시계

한글로 만든 시계 프로젝트를 모아 둔 갤러리입니다.

* [여러분의 한글시계 - 온라인 사이트](https://suapapa.github.io/site-hangulclocks)

## 시계 등록하기

직접 만든 한글시계나, 온라인에서 본 프로젝트를 등록할 수 있습니다.

1. `src/assets/hangulclocks.yaml`에 항목을 추가합니다.
2. PR 또는 이슈로 등록을 요청합니다.

## 개발 및 기여

설치, 빌드, Docker 배포 방법은 [AGENTS.md](./AGENTS.md)를 참고하세요.
